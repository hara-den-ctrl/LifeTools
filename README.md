# 健康コンシェルジュ Ver1.0.0

## Ver1.0.0 追加機能
- AI検索の回答を原材料・栄養・血糖・肝臓・尿酸・具体策の6区分へ詳細化
- 健康AI相談を新設（血糖/HbA1c・肝臓/脂肪肝・尿酸・飲酒・食事量に特化）
- AI検索・AI相談の取得情報からマイ商品DBへ登録
- 登録前に商品名・メーカー・原材料・アレルゲン・栄養情報・情報元を確認/編集
- マイ商品DB登録情報を次回判定で優先使用
- 一食からHbA1c/ALT/尿酸の検査値そのものを数値予言する表現を廃止し、影響傾向と理由を表示
- 既存の履歴編集・AI再判定・削除・献立・冷蔵庫・調味料・PWA機能を維持

※外部AI/APIには接続せず、端末内データと入力語句による参考判定として動作します。商品情報は現行ラベル・メーカー公式情報を優先してください。
