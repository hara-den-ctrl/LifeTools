# 健康コンシェルジュ Ver0.6

LifeTools向けの食事・買い物・健康記録Webアプリです。

## 主な機能

- 食材のチェックボックス選択
- 食材ごとの血糖・肝臓・尿酸の注意表示
- 選択食材と冷蔵庫在庫から献立候補を作成
- 調理時間、日本酒、軽め、期限優先などの条件指定
- 調味料と市販商品の健康注意表示
- キッコーマン 本つゆ 濃縮4倍の注意データ
- 冷蔵庫の在庫・期限管理
- 食事、水分、歩行、発汗、飲酒の記録
- HbA1c、ALT、尿酸の参考予測レンジ
- バーコード読込状態の表示
- 原材料OCRと注意原材料検出
- PWA対応
- 画面右上とフッターにVer0.6を表示

## GitHubへアップロードするファイル

ZIPを解凍し、次のファイルをLifeToolsリポジトリ直下へアップロードしてください。

- README.md
- UPLOAD_CHECK.txt
- app.js
- index.html
- manifest.webmanifest
- service-worker.js
- styles.css
- assets フォルダ

ZIPファイルそのものはアップロードしません。

## ファイル識別

- index.html は `<!doctype html>` で始まります。
- app.js は `const VERSION="0.6";` で始まります。
- README.md は `# 健康コンシェルジュ Ver0.6` で始まります。
- manifest.webmanifest は `{` で始まるJSONです。

## 通信

OCRとバーコード用ライブラリを初回に外部から読み込むため、Wi-Fiまたは携帯回線によるインターネット接続が必要です。

## 免責

健康評価や予測レンジは参考情報です。医療診断、血糖測定、血液検査の代替ではありません。
