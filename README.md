# 健康コンシェルジュ Ver0.8

## 更新内容（Revision 0.8.2）

- チェック式の野菜欄へ「ジャガイモ」「長芋」を追加
- チェック欄にない食材を自由入力で検索
- 血糖・肝臓・尿酸の評価、目安量、注意点を表示
- 登録済みの健康値を考慮したAI参考回答を表示
- 検索食材を選択食材へ追加し、そのままAI献立を生成
- 最近検索した食材を端末内に保存
- 未登録食材は「簡易判定」と明示

## GitHub Pagesへの更新

ZIP内のファイルをリポジトリ直下へすべて上書きしてください。`app.js`、`index.html`、`styles.css`、`service-worker.js`、`version.json`は必ず更新してください。

健康評価・AI回答・予測値は参考情報であり、診断や治療判断ではありません。
