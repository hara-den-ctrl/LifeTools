# 健康コンシェルジュ Ver0.9.2

## Ver0.9.2の改善内容
- NaN〜NaN表示の防止とデータ不足時の案内表示
- ホームの操作導線を「記録」「AI判定」に整理
- HbA1c・ALT・尿酸の色分けビジュアルアラート
- 保存済み履歴の編集
- 編集内容を使ったAI再判定と履歴の上書き
- 履歴の個別削除
- 個別削除・全削除時の確認ダイアログ

## 維持している主な機能
- AI検索・健康判定
- 食事内容、食材と量、調味料、飲み物、飲酒量などの記録
- 血糖・肝臓・尿酸の評価
- HbA1c・ALT・尿酸の参考傾向表示
- Service WorkerによるPWA・自動更新

※判定は端末内データと入力語句による参考情報です。診断や検査値を保証しません。
