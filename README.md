# 健康コンシェルジュ Ver0.8.3

## 更新内容
- 食べた献立名の自由入力
- 食材名と量の入力
- 調味料・飲み物・飲酒量の入力
- 食事量・食事区分・満腹度の入力
- 自由メモ
- 入力内容から血糖・肝臓・尿酸への影響傾向を表示
- HbA1c・ALT・尿酸値の参考予測レンジと傾向を表示
- 入力内容と予測結果をローカル履歴へ保存
- Service Worker、キャッシュ、画面内バージョン表示をVer0.8.3へ統一

## 注意
本アプリの評価・予測は生活記録に基づく簡易的な参考表示です。診断、検査値の実測、治療判断を行うものではありません。
